# Python Собес — флешки для подготовки к собеседованиям

Статический тренажёр-флешки по вопросам Python Backend собеседований.
191 карточка с грейдами **Джун / Мид / Синьер / Лид**, Anki-подобным интервальным
повторением, разворачиваемым контекстом и SVG-схемами. Без бэкенда и сборки —
один HTML + два JS-файла.

## Что внутри

- **191 вопрос с ответами** по темам: Python, asyncio, FastAPI, Django/DRF, SQL/PostgreSQL,
  Redis, очереди (Kafka/RabbitMQ), Docker, тесты, HTTP/безопасность, архитектура, алгоритмы, команда/лид.
- **Два режима:**
  - **Учить** — интервальное повторение (SM-2-подобный планировщик). После ответа —
    кнопки `Снова / Трудно / Хорошо / Легко`, карточка всплывёт снова через рассчитанный интервал.
  - **Все** — свободный просмотр с листанием и перемешиванием.
- **Фильтры** по теме и по грейду.
- **Контекст** — под ответом разворачивается блок «зачем спрашивают / частая ошибка / как копают глубже».
- **SVG-схемы** к наглядным темам (JOIN, event loop, N+1, Kafka, кеш-aside, CAP).
- **Светлая/тёмная тема**, адаптив под телефон. Прогресс хранится в браузере (localStorage).

## Как запустить локально

Просто открыть `index.html` в браузере — двойным кликом или:

```bash
# либо поднять локальный сервер (чтобы точно подхватились cards.js/context.js)
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как выложить в веб (GitHub Pages)

1. Создать репозиторий на GitHub и запушить файлы:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/py-interview-cards.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
3. Через ~минуту сайт будет на `https://<ваш-логин>.github.io/py-interview-cards/`.

Тот же набор файлов работает на любом статик-хостинге (Netlify, Vercel, Cloudflare Pages,
GitLab Pages) — просто залить папку.

## Как добавлять и править карточки

Весь контент — в двух файлах, редактируются обычным текстовым редактором.

**Карточка** — в `cards.js`:
```js
{
  c: "SQL",            // тема
  lvl: "Мид",          // грейд: Джун | Мид | Синьер | Лид
  q: "Вопрос?",        // лицевая сторона
  a: `<ul><li>Ответ (можно HTML)</li></ul>`,
  img: `<svg class="dgm" ...>...</svg>`   // опционально: схема
}
```

**Контекст** (разворачиваемый блок) — в `context.js`, ключ = ТОЧНЫЙ текст вопроса:
```js
window.CTX = {
  "Вопрос?": `<p><b>Зачем спрашивают:</b> ...</p>`,
};
```
Карточки без контекста просто не показывают блок — заполнять можно постепенно.

Про картинки: вместо внешних изображений используются встроенные SVG-схемы
(класс `dgm`, цвета через CSS-переменные — сами подстраиваются под тему). Внешние
картинки по ссылкам сознательно не используются: ненадёжно, вопросы копирайта и часто
нерелевантно к абстрактным темам.

## Структура

```
index.html    приложение (вёрстка + логика + планировщик повторений)
cards.js      window.CARDS — массив карточек
context.js    window.CTX — расширенные контексты по тексту вопроса
```
